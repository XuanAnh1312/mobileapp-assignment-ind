A new Flutter project.

## Chạy web tại cổng cố định

`web_dev_config.yaml` đặt địa chỉ mặc định là `http://localhost:8080`.

Mở bằng trình duyệt tùy chọn:

```sh
flutter run -d web-server
```

Sau đó mở `http://localhost:8080` trong trình duyệt bạn muốn sử dụng.
Để Flutter tự mở Chrome, chạy `flutter run -d chrome`.
Trong VS Code, chọn cấu hình `UTH Todo - Browser tùy chọn (8080)` hoặc
`UTH Todo - Chrome (8080)` tại Run and Debug rồi nhấn F5.
Chạy từng cấu hình một vì cả hai dùng chung cổng 8080.
